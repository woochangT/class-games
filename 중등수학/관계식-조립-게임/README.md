# 관계식 조립 게임

제시된 양(예: 걸린 시간)을 구하는 식을 단어·연산자 타일로 조립하는 반복 훈련 게임. 듀오링고식 문장 조립을 관계식에 옮겼다.

- 다루는 관계: 간 거리·빠르기·걸린 시간 / 진하기·농도·소금의 양·소금물의 양
- 진하기 = 소금의 양 ÷ 소금물의 양, 농도(%) = 소금의 양 ÷ 소금물의 양 × 100 (초등 교과처럼 구분)

## 실행

`index.html`을 브라우저에서 열면 된다. 인터넷이 연결되어 있으면 Jua·Noto Sans KR 글꼴을 불러오고, 없으면 시스템 글꼴로 보인다.

## 설정

| 항목 | 선택지 | 기본값 |
| --- | --- | --- |
| 문제 수 | 5 / 10 / 15 / 20 | 10 |
| 문제당 제한 시간 | 5 / 10 / 15 / 20 / 30초 | 20초 |
| 소금물 문제 | 진하기만 / 진하기 + 농도 섞기 | 진하기만 |

고른 설정은 브라우저에 저장된다.

## 채점

학생이 만든 식에 서로 맞는 무작위 값 3세트를 넣어, 결과가 모두 목표량과 같으면 정답이다. 그래서 순서만 다른 식(예: 걸린 시간 × 빠르기)도 정답으로 인정된다. 계산 순서는 교과서 규칙대로 ×·÷ 먼저, +·− 나중, 같은 급은 왼쪽부터.
